# 📝 Blog Post Listing - Modern React Blog Application

A modern, responsive blog application built with React, featuring search functionality, comment system, and optimized performance.

## 🌟 Features

### ✅ **Core Features**
- **📋 Blog Post Listing**: Clean, responsive layout for browsing posts
- **📝 Create/Edit Posts**: Rich text editor for content creation
- **🗑️ Delete Posts**: Safe deletion with confirmation dialogs
- **🔍 Advanced Search**: Real-time search with highlighting
- **💬 Comment System**: Interactive comment section for each post
- **📱 Responsive Design**: Mobile-first, works on all devices

### ⚡ **Performance Optimizations**
- **🚀 React.memo**: Optimized component re-rendering
- **🔄 Debounced Search**: Smooth, lag-free search experience
- **🖼️ Lazy Loading**: Images load only when needed
- **💾 Service Worker**: Caching for better performance
- **📊 Performance Monitoring**: Built-in performance tracking

### 🎨 **UI/UX Excellence**
- **🎯 Accessibility**: ARIA labels, keyboard navigation, screen reader support
- **🌙 Modern Design**: Clean, professional interface
- **⚡ Smooth Animations**: Micro-interactions and transitions
- **🛡️ Error Boundaries**: Graceful error handling

## 📦 Installation & Setup

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Local Development
```bash
# Clone the repository
git clone https://github.com/ShivaCharanReddyK/blog-post-listing.git

# Navigate to project directory
cd blog-post-listing

# Install dependencies
npm install

# Start development server
npm run dev

# Open http://localhost:5173 in your browser
```

### Build for Production
```bash
# Create production build
npm run build

# Preview production build
npm run preview
```

## 🚀 Deployment

### GitHub Pages (Automatic)
The application is automatically deployed to GitHub Pages using GitHub Actions when you push to the main branch.

### Manual Deployment
```bash
# Build and deploy to GitHub Pages
npm run deploy
```

## 🔧 Development Scripts

```bash
npm run dev        # Start development server
npm run build      # Build for production
npm run preview    # Preview production build
npm run deploy     # Deploy to GitHub Pages
```
